# Team Task Manager

A full-stack MERN application for managing projects and tasks.

## Setup Instructions

### Backend
1. `cd backend`
2. `npm install`
3. Create a `.env` file from `.env.example` and add your `MONGO_URI`.
4. `npm run dev`

### Frontend
1. `cd frontend`
2. `npm install`
3. Create a `.env` file from `.env.example`.
4. `npm run dev`
